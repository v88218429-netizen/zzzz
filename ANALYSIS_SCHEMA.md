# Default analysis schema

After a video request, the final user-facing result is not a list of links. The pipeline target is:

`request -> select videos -> transcribe -> analyze -> return digest`

## Single video

1. **Короткая суть** — 5–15 тезисов без воды.
2. **Транскрипция** — полный текст; сохранять таймкоды, если источник их даёт.
3. **Цифры и факты** — ставки, бюджеты, проценты, сроки, конверсии, формулы, лимиты, примеры.
4. **Что рекомендует автор** — конкретные правила и алгоритмы действий автора, без подмены его позиции.
5. **Что применимо к нашей работе** — привязка к Wildberries/магазинам/рекламе/остаткам/юнит-экономике пользователя только там, где это прямо следует из материала.
6. **Что забрать в WB AI Agent** — правила, триггеры, метрики, проверки, автоматизации, знания для базы агента.
7. **Противоречия / спорные места** — внутри ролика или с уже известными материалами; не выдумывать конфликт там, где его нет.
8. **Конкретные задачи на внедрение** — что можно добавить в таблицы, ботов, мониторинги, регламенты, агента.

## Batch / search collection

For each video keep an individual transcript and short per-video digest. Then produce one cross-video synthesis:

1. **Главные выводы всех видео**.
2. **Что повторяют 2+ авторов** — указывать количество независимых видео/авторов, поддерживающих тезис.
3. **Где авторы расходятся** — позиция A vs позиция B, без искусственного выбора победителя.
4. **Уникальные идеи** — сильные мысли, встречающиеся только у одного автора.
5. **Цифры / диапазоны / пороги** — объединённая таблица значений с источником каждого значения.
6. **Рабочая схема** — консолидированный алгоритм по теме (например: запуск рекламы -> сбор данных -> минусация -> масштабирование -> контроль ДРР).
7. **Что устарело или относится к старому интерфейсу/правилам** — учитывать дату видео.
8. **Что применить к текущим товарам пользователя** — без общих советов, только конкретные применения.
9. **Что добавить в WB AI Agent** — новые правила, проверки, эвристики, поля данных и автоматизации.
10. **Приоритет внедрения** — Now / Next / Later, только для технических/операционных задач, не политические или иные оценочные темы.

## Fidelity rules

- Сначала передавать смысл автора, потом отдельно нашу операционную интерпретацию.
- Не добавлять научную/мировоззренческую критику, если пользователь её не просил.
- Не превращать духовную/авторскую технику в другой метод.
- Не выдавать описание видео или название за фактическую транскрипцию.
- Если транскрипт недоступен, прямо пометить материал как `metadata/description only`, а не делать вид, что видео просмотрено полностью.
- Для поиска по YouTube конечный ответ должен содержать анализ транскрибированных видео, а не просто подборку ссылок.
