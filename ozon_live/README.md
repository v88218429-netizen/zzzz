# Ozon Live Rank Scanner

Реальная проверка выдачи Ozon через Chrome, отдельно по городам.

Первый production-probe:
- товар: Лоток_К_18шт_6
- SKU: 4832817032
- запрос: органайзер для саморезов
- города: Москва, Ростов-на-Дону, Краснодар
- глубина: TOP-300

Результат сохраняется в `ozon_live/results/latest.json`.

Важно: это live-слой, а не Sellmonitor. Он отражает то, что увидел браузер в конкретном городе в момент проверки. Ozon может менять выдачу из-за A/B, персонализации, рекламы и доступности доставки.
