# Evidence hierarchy

Use sources in this priority order:

1. Current Wildberries Seller API response for this seller/account and timestamp.
2. The seller's own historical snapshots and experiment ledger.
3. Current official Wildberries API/documentation snapshots maintained by the backend.
4. Client-specific policies and unit economics configured during onboarding.
5. Public WB marketplace observations for competitors/search visibility.
6. Generic marketplace heuristics only as a hypothesis generator, never as decisive evidence.

Never present a generic CTR, DRR, conversion or bid benchmark as a universal WB norm. Once a seller has enough history, compare primarily against that seller's own product/category/season baseline.

For any money-changing proposal, cite at least one live seller source and one policy/economic constraint. If either is missing, do not stage the change.
