# Incident investigation

1. Establish the exact start time/window of the anomaly.
2. Build a timeline of interventions: bid/budget changes, price/promotions, stock movements, card edits, supply status, API degradation and competitor changes.
3. Compare the affected SKU/campaign with its own prior baseline and, where useful, unaffected controls.
4. Generate multiple hypotheses; do not promote one to cause until evidence discriminates it.
5. Prefer reversible containment actions while diagnosis is uncertain.
6. Link every conclusion to source snapshots and timestamps.
7. Record the incident, the action taken and the post-action result so the case becomes future training/knowledge material.
