# Unit economics

Use seller-specific facts. Never replace missing cost data with marketplace averages.

For each SKU, distinguish:
- customer/order revenue basis;
- commissions and payment costs;
- forward/reverse logistics;
- storage/acceptance/penalties when relevant;
- tax basis configured for the seller;
- product cost;
- expected cancellation/return effect;
- advertising cost.

A break-even advertising threshold is derived from contribution margin before advertising. Show assumptions explicitly. If material cost components are missing, report a range or block spend-changing recommendations rather than fabricate precision.
