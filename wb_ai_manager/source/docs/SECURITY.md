# Модель безопасности v1.1

Текущая сборка работает только на чтение.

## Жёсткие ограничения

- `FORCE_READ_ONLY=true`;
- режим исполнения — наблюдение;
- автоматические действия отключены;
- запрос подтверждения не снимает жёсткую блокировку записи;
- интерфейс не содержит кнопки применения денежного изменения WB;
- бизнес-правила не могут расширить технические пределы или отключить защиту.

## Самообновление

Обновление кода устанавливается только из опубликованного стабильного канала. До установки проверяется контрольная сумма. Существующая версия резервируется; после установки выполняется проверка импорта/компиляции; при сбое код откатывается.

Патчам запрещено изменять пользовательские `.env`, `data/`, `config/catalog.csv` и `config/watch_queries.yaml`. При неудачной установке новые системные config-файлы удаляются, а пользовательские сохраняются.

## Защита аналитики

- общая статистика многотоварной кампании не приписывается отдельному SKU;
- свежая когорта не оценивается как зрелая;
- чужое ручное действие не засчитывается как выполненная рекомендация агента;
- при критическом ограничении увеличение ставки/расхода замораживается во всех представлениях решения.
