# Управляющее ядро v1.1

Специализированные агенты не должны независимо давать противоречащие друг другу денежные советы. Их задача — собирать и нормализовать факты. Итоговое решение формирует одно управляющее ядро.

## Цепочка

1. Проверка свежести источников.
2. Сбор фактов по товару/кампании/магазину.
3. Расследование причин и недостающих данных.
4. Расчёт вариантов действия.
5. Независимый критик пытается найти ошибку.
6. Контроль риска проверяет юнит-экономику, остатки, зрелость когорт и технические пределы.
7. Формируется итоговое числовое решение.
8. Решение сохраняется в историю.
9. Фактическое изменение фиксируется отдельно.
10. Контроль результата выполняется через 1ч / 3ч / 24ч / 7д / 14д.

## Жёсткие требования

- для рекламы денежное решение строится по точной паре `кампания + nmID`;
- общие показатели многотоварной кампании нельзя выдавать за показатели отдельного товара;
- свежие заказы нельзя оценивать выкупами той же календарной недели без учёта зрелости;
- отсутствие юнит-экономики, точной рекламной статистики или других критичных данных блокирует увеличение денежного воздействия;
- при блокировке текст, ставка и лимит расхода должны быть согласованы;
- исторические корреляции не объявляются доказанной причинностью;
- для обучения используются только фактически замеченные действия, совпавшие с рекомендацией; подтверждённое бездействие «оставить ставку» тоже учитывается; последующее вмешательство обрывает атрибуцию старого решения.

Сборка v1.1 работает только в режиме чтения: управляющее ядро не вызывает инструменты записи WB.
