# Автоматическое обновление WB AI Manager

## Два канала изменений

### 1. Бизнес-правила
`wb_ai_manager/policy.json` читается примерно раз в минуту. Меняются без перезапуска процесса. Здесь находятся пороги, стратегии, исключения по группе/SKU и аналитические принципы.

### 2. Код
`wb_ai_manager/update-manifest.json` указывает стабильную версию и архив. Надсмотрщик:
1. сравнивает версию;
2. останавливает рабочий процесс;
3. создаёт резервную копию;
4. скачивает архив;
5. проверяет SHA-256;
6. не затрагивает `.env`, `data/`, `.venv`, `config/catalog.csv`, `config/watch_queries.yaml`;
7. обновляет код и зависимости;
8. выполняет compile + smoke;
9. при успехе запускает новую версию;
10. при ошибке откатывает резервную копию и запускает предыдущую.

## Что не является самообновлением

Агент не генерирует и не исполняет произвольный новый код самостоятельно. Стабильное обновление сначала должно быть опубликовано в канале обновлений. Это позволяет тестировать исправление до применения на рабочем магазине.

## Быстрые патчи

Стабильный канал поддерживает файловые патчи. Для небольшого исправления не требуется выкладывать весь дистрибутив: манифест перечисляет изменённые файлы, их SHA-256 и новую `VERSION`. После патча всё равно выполняются резервная копия, установка зависимостей, smoke-проверка и откат при ошибке.
