# Trusted data map v0.5

## Приоритет

1. Live WB Seller API (если токен подключён и endpoint валиден).
2. `Остатки v.1 27июля` для текущих остатков/FF/юнитки/товарного справочника.
3. Свежая недельная сводка AIR + Саныч + Хозяюшка для экономики и period comparison.
4. Sellmonitor Саныча для exact-day истории.
5. FBS клиентские таблицы — только при подтверждённой свежести.
6. Legacy Дублинский — история/справка.

## Правило stale-source

Более старый источник никогда не должен перезаписывать более свежий факт того же типа. Источник с нулевым/сломавшимся срезом получает статус `broken` и исключается из финансовых выводов до восстановления.

## 27 + Юнитка

`Остатки v.1 27июля` содержит единый набор полей: остатки FF/K2, FBW/FBS, заказы/продажи, товары, себестоимость и вкладку `Юнитка`. Это основной операционный контур для собственного магазина в v0.5.
