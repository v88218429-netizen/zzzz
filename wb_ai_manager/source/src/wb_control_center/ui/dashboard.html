БАЗА ЗНАНИЙ

Почему агент делает именно такой вывод

WB AI Manager не должен опираться на «память модели». Решения проходят через иерархию источников и версионируемые правила.

ПРАВИЛА
01ЖИВЫЕ ДАННЫЕ

Wildberries сейчас

Реклама, заказы, цены, позиции, остатки, финансы, карточки и обращения читаются из API продавца WB конкретного магазина.

Самый высокий приоритет
02HISTORY

История магазина

Снимки показателей, прошлые инциденты, изменения и результаты экспериментов формируют собственный baseline магазина.

Приоритет выше универсальных бенчмарков
03ОФИЦИАЛЬНО

Спецификации WB

Единицы ставок, статусы кампаний, лимиты API и доступные операции должны сверяться с актуальными спецификациями.

Версионируемый источник
04ПРАВИЛА

Правила бизнеса

Целевой ДРР, экономика товара, дни запаса, минимальная выборка и допустимые сценарии задаются отдельными policies.

Настраивается под продавца
05HEURISTICS

Эвристики

Общие ориентиры CTR/CR/ДРР используются только как подсказки и сигналы, но не как основание для денежного действия.

Самый низкий приоритет
РЕКЛАМНАЯ ЛОГИКА

Цепочка принятия решения

1Собрать фактыРасход, заказы, ДРР, CTR, CPC, позиции, остатки, цена.
2Проверить достаточностьНе делать вывод на слишком малой выборке или сразу после изменения.
3Диагностировать причинуСначала цена/CR/остатки/позиции, только потом рекламная ставка.
4Сформировать рекомендациюРекомендация содержит измеренные факты и источник.
5Защитный контурВ этой сборке любое изменение WB физически заблокировано.
