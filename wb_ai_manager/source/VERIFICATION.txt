19. non-finite numeric values (NaN/Infinity) could bypass some hard money caps because IEEE comparisons return false;

24. Public competitor search silently hardcoded a geo destination (`dest=-1257786`) without provenance.
    FIX: destination is now a Settings value (`PUBLIC_WB_DEST`) and every competitor snapshot records `search_dest`.
    Default behavior is preserved rather than changing marketplace geography during an audit.

25. Browser-based Sheets launcher used an unbounded `subprocess.run(open ...)`.
    FIX: 10-second process deadline; a stuck OS launcher degrades to no refresh instead of hanging the agent.

26. Normal exception rollback could report `rollback=ok` without checking pip refresh return code or post-restore smoke.
    FIX: rollback is now successful only after restore + dependency refresh + smoke verification; failures are recorded as rollback failures.

27. Background full-audit tasks were not explicitly drained before runtime shutdown.
    FIX: lifespan shutdown now cancels/awaits tracked audit tasks before closing the ControlCenter/WB connector.
