# WB product image quality control

Use for Wildberries primary image and product-card slide variants. The input product photo is the source of truth, never a generated approximation.

1. Verify the exact reference images and SKU. Preserve shape, material, colors, edges, holes/perforation, handles, lid, and all other construction features. Do not invent a new basket, change weave patterns, add a sticker, or paint over defects as if it were a faithful original.
2. Keep primary image and additional slides separate. Produce independent image assets; never replace an A/B test set with a collage.
3. Respect the requested marketplace format, user-supplied typography and design system. Distinguish the primary click-through headline from secondary claims. Retain 3–4 strong relevant selling points if requested; do not remove them during revisions.
4. Use only verified dimensions and capacities. Keep perspective and scale consistent with the scene. A corner basket with a true 90-degree rear angle must not become an 82-degree wedge. Do not duplicate the same dimension without a reason.
5. If the user requests an exact object insertion, editing or compositing the original photo is preferred to reimagining the object. Explicitly flag when pixel-level product fidelity cannot be established.
6. Perform visual QA before delivery: identity vs reference; symmetry and geometry; material/perforation continuity; no tears, smears, inconsistent whites, ghosted text, random lines, or watermarks; legible concise Russian copy; no cropped handles/lid.
7. For A/B testing, vary ONE intentional concept per variant (scene, palette, headline hierarchy or composition); keep the underlying product and factual claims fixed. Record variant ID and hypothesis.
8. Never state that a visually generated product is identical to the original without checking. Report remaining mismatches openly.

This skill is guidance for a supported image tool; it does not itself generate or alter an image.
